# Client Registry — ইনস্টিটিউশন ক্লায়েন্ট ম্যানেজমেন্ট ওয়েব অ্যাপ

Next.js 14 + Prisma + Neon Postgres (Vercel Marketplace) দিয়ে বানানো একটি ফুল-স্ট্যাক CRUD অ্যাপ। কোনো Google Sheet সংযোগ নেই — সব ডাটা একটি আসল Postgres ডাটাবেজে থাকে। নিচের পুরো সেটআপ **সম্পূর্ণ ফ্রি**।

## ফ্রি রাখার হিসাব

| জিনিস | কোথায় | ফ্রি প্ল্যান |
|---|---|---|
| কোড হোস্টিং | GitHub | ফ্রি (পাবলিক/প্রাইভেট রিপো) |
| ওয়েব অ্যাপ হোস্টিং | Vercel (Hobby plan) | ফ্রি — 100GB ব্যান্ডউইথ, 1M ফাংশন কল/মাস |
| ডাটাবেজ | Neon (Vercel Marketplace-এর মাধ্যমে) | ফ্রি — 0.5GB স্টোরেজ, যথেষ্ট একটি প্রতিষ্ঠান-তালিকার জন্য |

⚠️ **একটা গুরুত্বপূর্ণ শর্ত**: Vercel-এর Hobby (ফ্রি) প্ল্যান টেকনিক্যালি "non-commercial / personal use"-এর জন্য। এই টুলটা যেহেতু তোমার প্রতিষ্ঠানের ইন্টারনাল ডাটা ম্যানেজমেন্টের কাজে ব্যবহার হবে (কোনো ভিজিটর থেকে সরাসরি টাকা নেওয়া হচ্ছে না), অধিকাংশ ছোট প্রতিষ্ঠান/ফ্রিল্যান্সার এভাবেই ফ্রি প্ল্যানে চালান এবং Vercel এটা নিয়ে সাধারণত কিছু বলে না। তবে ভবিষ্যতে ট্র্যাফিক অনেক বাড়লে বা এটাকে সরাসরি বাণিজ্যিক পণ্য হিসেবে বিক্রি করলে Pro প্ল্যান ($20/মাস) লাগতে পারে। Neon-এর ফ্রি প্ল্যানে ডাটাবেজ ৫ মিনিট নিষ্ক্রিয় থাকলে "sleep" করে — পরের রিকোয়েস্টে ১-২ সেকেন্ড বাড়তি সময় লাগতে পারে, ব্যবহারে কোনো বাধা নেই।

## ফিচার

- প্রতিষ্ঠান Add / Edit / Delete
- ডিফল্ট কলামে: নাম, ওয়েবসাইট, ইসু ডেট, এক্সপায়ার ডেট, স্ট্যাটাস — বাকি সব তথ্য রো ক্লিক করলে বিস্তারিত অংশে দেখা যায়
- স্ট্যাটাস অটো-ক্যালকুলেটেড: Active / Expiring Soon (৬০ দিনের মধ্যে) / Expired / Actual Expired
- সার্চ: নাম, ফোন, ওয়েবসাইট, প্রতিষ্ঠান প্রধানের নাম দিয়ে
- ফিল্টার: সাব-ডিস্ট্রিক, ডিস্ট্রিক, স্ট্যাটাস, প্রতিষ্ঠানের ধরন, ক্যাটাগরি
- প্রয়োজন অনুযায়ী কাস্টম ফিল্ড যোগ করার অপশন (text / number / date)

## লোকাল সেটআপ

```bash
npm install
```

`.env` ফাইল বানাও (`.env.example` কপি করে) এবং তাতে তোমার Postgres কানেকশন স্ট্রিং বসাও। তারপর:

```bash
npm run db:push   # ডাটাবেজে টেবিল তৈরি করবে
npm run dev        # http://localhost:3000
```

## সম্পূর্ণ ফ্রি ডিপ্লয়মেন্ট — স্টেপ বাই স্টেপ

### ধাপ ১ — কোড GitHub-এ তোলা

1. [github.com](https://github.com) -এ ফ্রি অ্যাকাউন্ট বানাও (না থাকলে)।
2. একটি নতুন খালি রিপোজিটরি বানাও (যেমন `Imp-database`) — Public বা Private, দুটোই ফ্রি।
3. এই ফোল্ডারের ভেতরে গিয়ে:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/hisam84/Imp-database.git
   git push -u origin main
   ```

### ধাপ ২ — Vercel-এ ফ্রি অ্যাকাউন্ট ও প্রজেক্ট ইম্পোর্ট

1. [vercel.com](https://vercel.com) -এ **GitHub দিয়ে সাইন আপ** করো (এটি অটোমেটিক্যালি Hobby/ফ্রি প্ল্যানে শুরু হয় — কোনো কার্ড লাগে না)।
2. **Add New → Project** ক্লিক করো।
3. তোমার `Imp-database` রিপোজিটরি সিলেক্ট করে **Import** করো।
4. Framework Preset অটোমেটিক্যালি "Next.js" ধরবে। এখনই Deploy চাপবে না — আগে ধাপ ৩ করে নাও যাতে ডাটাবেজ ভ্যারিয়েবলসহ একবারেই বিল্ড হয়।

### ধাপ ৩ — ফ্রি Neon ডাটাবেজ যুক্ত করা

1. প্রজেক্টের **Storage** ট্যাবে যাও (অথবা Import স্ক্রিন থেকেই "Connect a Database" অপশনে যাও)।
2. **Marketplace Database Providers** থেকে **Neon** সিলেক্ট করো → **Add Integration**।
3. Neon-এর নিজস্ব সাইন-আপ/লগইন হবে (GitHub দিয়েই করা যায়, ফ্রি) — এরপর **Free Plan** সিলেক্ট করে একটি ডাটাবেজ প্রজেক্ট বানাও ও তোমার Vercel প্রজেক্টের সাথে **Connect** করো।
4. Connect হলে Vercel নিজে থেকেই `DATABASE_URL` এবং `DATABASE_URL_UNPOOLED` এনভায়রনমেন্ট ভ্যারিয়েবল প্রজেক্টে যোগ করে দেবে — এগুলো আলাদা করে টাইপ করার দরকার নেই।

### ধাপ ৪ — Deploy করা

1. এখন **Deploy** বাটনে ক্লিক করো।
2. বিল্ড শেষ হলে অ্যাপ একটা ফ্রি `.vercel.app` লিংকে লাইভ হয়ে যাবে, কিন্তু ডাটাবেজে এখনো কোনো টেবিল তৈরি হয়নি — পরের ধাপে সেটা করব।

### ধাপ ৫ — ডাটাবেজে টেবিল তৈরি করা (একবারই লাগবে)

1. Vercel Dashboard → তোমার প্রজেক্ট → **Settings → Environment Variables** থেকে `DATABASE_URL` আর `DATABASE_URL_UNPOOLED`-এর ভ্যালু কপি করো।
2. লোকাল প্রজেক্ট ফোল্ডারে `.env` ফাইলে সেগুলো বসাও।
3. রান করো:
   ```bash
   npm run db:push
   ```
4. এটি Prisma schema অনুযায়ী `Institution` আর `CustomFieldDefinition` টেবিল বানিয়ে দেবে Neon-এর ডাটাবেজে।

> বিকল্প: `npm i -g vercel` দিয়ে Vercel CLI ইনস্টল করে `vercel env pull .env` কমান্ডে এই ভ্যারিয়েবলগুলো সরাসরি টেনে আনতে পারো — ম্যানুয়ালি কপি-পেস্ট করতে হবে না।

### ধাপ ৬ — যাচাই করা

Vercel-এর দেওয়া `.vercel.app` লিংকে ঢুকে **+ Add Institution** চেপে একটি টেস্ট প্রতিষ্ঠান যোগ করে দেখো। তালিকায় দেখা গেলে বুঝবে সব ঠিকভাবে কানেক্টেড।

### নিজের ডোমেইন যুক্ত করা (ঐচ্ছিক, তবে সেটাও ফ্রি)

Vercel-এর ফ্রি `.vercel.app` সাবডোমেইন যথেষ্ট হলে কিছু করার দরকার নেই। নিজের ডোমেইন (যেমন `clients.তোমারডোমেইন.com`) যুক্ত করাও Vercel-এ ফ্রি — শুধু ডোমেইনটা কেনার খরচ থাকে (Vercel নিজে ডোমেইন কেনায় চার্জ করে না)।

### পরবর্তী আপডেট

এরপর থেকে `main` ব্রাঞ্চে যেকোনো কোড পুশ করলেই Vercel অটোমেটিক্যালি ফ্রি-তে নতুন ডিপ্লয় করবে। schema.prisma-এ কোনো পরিবর্তন আনলে সেই পরিবর্তন প্রোডাকশন ডাটাবেজে আনতে আবার `npm run db:push` (লোকাল `.env` দিয়ে) রান করতে হবে।

## কাস্টম ফিল্ড কীভাবে কাজ করে

"Custom Fields" বাটনে ক্লিক করে নতুন ফিল্ড (যেমন EIIN নম্বর) যোগ করলে সেটি প্রতিটি প্রতিষ্ঠানের ফর্মে দেখা যাবে এবং ডিটেইলস প্যানেলে প্রদর্শিত হবে। এই ভ্যালুগুলো প্রতিটি প্রতিষ্ঠানের রেকর্ডে JSON আকারে সংরক্ষিত থাকে, তাই নতুন ফিল্ড যোগ করার জন্য ডাটাবেজ মাইগ্রেশনের দরকার হয় না।
